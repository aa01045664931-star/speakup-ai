# SpeakUp AI

AI 발표 코치 웹앱입니다. 발표 녹음, 웹캠 화면, 말 속도/말버릇/자세 분석 느낌의 피드백, 성장 기록 그래프를 구현했습니다.

## 실행 방법
1. VS Code에서 이 폴더를 엽니다.
2. `index.html`을 Live Server로 실행합니다.
3. 카메라와 마이크 권한을 허용합니다.

## GitHub Pages 배포
1. GitHub에서 새 repository를 만듭니다.
2. 이 폴더 안의 파일을 모두 업로드합니다.
3. Settings → Pages → Branch를 `main`으로 선택합니다.
4. 저장 후 배포 링크를 확인합니다.
